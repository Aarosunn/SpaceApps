- Fit as a sonification source: **good** — Real, current satellite observation with a machine-readable UTC timestamp in every file name, fixed geometry, almost no clutter and a strong natural rhythm (day/night every 144 frames, moving storms). - Suggested mapping: Pre-process offline: take every 6th file (hourly) or all 144 per day, downscale to about 256x256, mask the disk. Per frame compute mean luminance in a 3x3 grid of regions (or latitude bands): each region is one voice, luminance (cloud cover / sunlight) -> loudness and brightness of timbre, region x-position -> stereo pan, region y-position -> pitch (north high, south low). Global sunlit fraction -> a low drone filter cutoff that opens at local day and closes at night, giving an audible 24-hour cycle. Speak the UTC time parsed from the file name at each 00:00 and on demand for screen-reader users. At 12 frames/s one day lasts 12 s and the full 5.5 days about 66 s.

## Frame → time mapping

## Gotchas

- NOT one image per day: one frame = 10 minutes, 144 frames per day, 795 frames per satellite.
- The '2160x2160' in the folder and file names is false: files are 10848x10848 baseline JPEGs of 9.5-17.6 MB each (verified via JPEG SOF header and Content-Length). Never fetch the whole folder; pick a subsample and downscale.
- Both MP4s listed on the page (PR_WorldView_geostationary_east_2160x2160_en.mp4 '1.1 GB', PL_..._west_... '1.0 GB') return HTTP 404. There is no playable movie; only the JPEG folders work.
- Rolling window: file names change every day; frames older than about 5.5 days are deleted, so hard-coded URLs will 404. Copy what the demo needs to your own storage.
- Not real-time: one batch per day lands about 04:00-04:30 UTC (22:00-22:30 CST the evening before); between batches the newest frame is up to about 25 h old. At 19:28 UTC today the newest east frame was 16 h 08 min old.
- Description and dataset credit say GOES-16; the actual files are GOES19_* (GOES-East) and GOES18_* (GOES-West). Files win.
- Page says 796 item(s) per folder; the live listing has 795 in each.
- Timestamps are UTC, not US Eastern (the EDT note for GEOS daily movies does not apply here). Proof besides the burned-in 'UTC' label: the 03:20 file was written at 04:14:50 UTC, so 03:20 cannot be a US local time.
- The print.jpg stills are static files from 23 Jun 2023 with an EDT label at the bottom; current frames put a UTC label in the upper-left. Do not build OCR or layout assumptions from the stills.
- CORS: response header is access-control-allow-origin: https://tempo.multiverse.music (fixed, another site). A browser app on any other origin cannot read pixels via canvas or fetch(); proxy or pre-download.
- Night-side city lights are a static layer (not live data) and night colors are false color; a brightness-to-sound mapping will jump at the terminator and must not present city lights as observations.
- East and West windows are offset by 20 minutes (east 15:00-03:20, west 15:20-03:40); pair them by timestamp, not by index.
- The folder listing is an HTML page with names only (no sizes or dates); the SVS API record does not list individual frame files. Scrape the listing with a regex such as GOES1[89]_\d{11}_2160x2160\.jpg.
- Geostationary perspective: pixel position is not latitude/longitude; a regional mapping needs the GOES fixed-grid projection or hand-drawn region masks.
