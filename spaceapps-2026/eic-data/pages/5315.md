## Quick answer

- What it is: A single still world map of the GEOS-based Fire Weather Index one-day forecast for the current day, overwritten once a day (today's file is labelled '14 Nov 2026'); no movie, no frame set, no archive.
- Kind: data-still-image
- Data source: Global Fire Weather Index (GlobalFWI / GFWED) produced at NASA GISS from NASA GMAO GEOS weather forecasts. Bundle: 'Fire Weather Index | common name: GlobalFWI | platform: GEOS-5 model | type: Model'. (model)
- Period covered: One day only: the current day. Today's image is labelled '14 Nov 2026'. No past days are published on the page.
- Time step of the underlying data: Daily (one one-day forecast per day), per NASA: 'the daily one-day forecast of the Fire Weather Index'.
- **One frame equals**: There is exactly one image and it represents one forecast day (the day printed on it). There is no sequence, so no per-frame arithmetic applies.
- **One frame = one day?**: not-applicable
- Where a program gets a frame's date: File name carries no date (always FWI_forecast_latest.png). Date comes from the burned-in label (OCR) or from the HTTP Last-Modified header date. dated_sets.json has no entry for this page.
- Date label seen on screen: Light-blue rounded legend box, lower left: '14 Nov 2026' / 'Fire Weather Index' / swatches 'Very Low' (green), 'Low' (yellow), 'Moderate' (orange), 'High' (red-orange), 'Very High' (dark red), 'Extreme' (near-black purple), 'No Calculations (unvegetated / snow)' (grey). No clock time, no time zone, no numeric scale, no NASA logo.
- Update behaviour: The same file names are overwritten daily; nothing accumulates. All four images share Last-Modified Sat, 14 Nov 2026 07:10:51-52 GMT, and the page record itself was 'last updated 2026-11-14T02:10:52-05:00' (= 07:10:52 UTC), i.e. the render lands around 07:10 UTC (02:10 US Eastern). Label date 14 Nov 2026 = render date, lag 0 days (it is a forecast for the current day).
- Status on 2026-11-14: updating-daily — newest data: 14 Nov 2026 (label on the image fetched today; forecast for the current day).
- View / camera: Static oval pseudo-cylindrical world map (Equal-Earth/Robinson-like, curved edges; corners are black in the JPEG preview) - not equirectangular, so x,y does not map linearly to lon/lat. Fixed geography, no camera motion.
- On-screen clutter: One legend box covering roughly the lower-left 15 percent of width and 40 percent of height (over the SE Pacific; no land data hidden except part of West Antarctica). Grey shaded-relief background on land and ocean where there is no calculation.
- Clean variant: No. Only the labelled image exists (plus print/thumbnail copies). The full PNG is RGBA (colour type 6); whether the corners outside the oval are transparent was not checked.
- What the colours mean: Categorical Fire Weather Index classes (API description of media group 374705): Very Low < 10.0 (green); Low 10.0-20.0 (yellow); Moderate 20.0-40.0 (orange); High 40.0-50.0 (red-orange); Very High 50.0-70.0 (dark red); Extreme > 70.0 (near-black purple); grey = no calculation (unvegetated or snow-covered). Higher class = weather more favourable to fire starting and spreading; it is not a map of actual fires.
- Fit as a sonification source: **fair** — Six flat, well-separated categorical colours make it easy to classify pixels reliably and the image is always today's date, but it is a single still: there is no time axis to play, only a spatial scan, and no history unless the team saves a copy each day (two copies at most before the deadline). The oval projection also complicates naming places.
- Suggested mapping: Spatial scan: sweep a vertical line west to east across the map over about 20 s; for each column classify pixels to the six legend colours and play one note per class present, pitch rising and timbre roughening from Very Low to Extreme, loudness = share of the column in that class, vertical position -> stereo or octave. Alternative for accessibility: touch/keyboard exploration where the cursor position speaks the class ('Extreme') and plays its tone. Pairs well with 5113: forecast risk (5315) as a drone under the observed-fire crackle (5113).
