## Quick answer

- What it is: GEOS model of CO2 added to the atmosphere through 2021, split into fossil fuel / biomass burning / land / ocean; 20 movies, mostly 3D globes or a 3D volume box plus a bar-chart and a month timeline.
- Kind: data-animation
- Data source: GEOS Carbon Dioxide (NASA GMAO model, scientist Lesley Ott); NASA SVS 5110 (bundles/5110.md lines 14, 41) (model)
- Period covered: Jan to Dec 2021 (bundle line 41: 'over the course of the year 2021'; frame set names 'JanToDec2021_...'). The year is NOT burned into any picture; only month ticks Jan..Dec appear.
- Time step of the underlying data: INFERRED 3-hourly: 2920 frames / 365 days = 8.0 frames per day = 3 h per frame. Cross-check on explainer timeline bar: at t=40 s bar filled to x=363 of 67..1220 (0.257 of year = day ~94), at t=79 s to x=826 (0.658 = day ~240); 146 days / 39 s = 3.75 d/s = 0.125 d/frame at 30 fps = 8 frames/day. Matches.
- **One frame equals**: 3 hours of 2021 (inferred) in the 2920-frame movies/frame sets (97.33 s at 30 fps). 2920 is not 365 x 30. The explainer (3600 frames, 120 s) and composite (3150 frames, 105 s) have intro/outro or non-uniform pacing, so are NOT a clean 8 frames/day.
- **One frame = one day?**: no
- Where a program gets a frame's date: 2021-01-01 (inferred; no file name carries a date)
- Date label seen on screen: No date text and no year. Only a month-tick timeline bar (Jan..Dec) with a growing white progress line in explainer and composite, and the separate TIMELINE_ORTHO movie (4096x1080, grey month ticks). Explainer also burns labels: 'fossil fuel emissions', 'biomass burning emissions', 'ecosystem exchange', 'ocean exchange', 'land absorption', 'ocean absorption'; bars labelled land / ocean / biomass burning / fossil fuels / TOTAL with axis +3 ppm to -3 ppm. No NASA logo seen in sampled frames.
- Update behaviour: Static. Released 2023-06-16; page record updated 2026-01-05. Fixed 2021 model run. Some files re-encoded later (explainer mp4 Last-Modified 2025-10-24, explainer frame set 2025-11-24, waterfall mp4 2024-02-14, some EXR sets 2024-02-14) but same 2021 data; .webm copies from 2023-06/11. No rolling window.
- Status on 2026-11-14: static
- View / camera: Mixed. Explainer/composite: three orthographic globes (Americas, EMEA, Asia/Australasia) whose view angle and size change during the year (explainer t=40 s: one big centre globe + two small; t=79 s: three equal globes), with volumetric CO2 haze and white coastlines. Group 312177 (1920x1080) is a tilted perspective 3D volume box showing the whole map with altitude labels 0/4/9/14/19 km, not a clean flat map. Per-region 2160x2160 globe movies. Waterfall (920x1024) and legend are charts.
- On-screen clutter: Heavy in explainer/composite (legends, 3D layer key, bars, timeline, annotations). Cleaner: regional 2160x2160 globe movies (no timeline/legend), timeline-only and legend-only movies as separate layers. No alpha layers, no unannotated flat map, no data-only layer. EXR frame sets are RGB renders (7 to 33 GB), not raw ppm data.
- Clean variant: Partly: timeline-only (4096x1080, 3.1 MB mp4) and legend-only movies exist; regional globe movies lack timeline; no flat unannotated map, no date-free/colorbar-free data layer.
- What the colours mean: No numeric colorbar on the globes. Colour = which tracer dominates (yellow/tan fossil fuel, red biomass burning, green land, blue/teal ocean); brightness/opacity = volumetric CO2 enhancement, not quantified on screen. Only the waterfall bar chart has a numeric axis (-3 to +3 ppm).
- Fit as a sonification source: **fair** — Globes rotate/zoom in perspective with hazy volume and no numeric colorbar, so a cursor cannot return a true ppm value. Colours do separate the four sources and the seasonal rhythm shows in the waterfall bars, which are cleanly readable against a fixed -3..+3 ppm axis.
- Suggested mapping: Use the waterfall movie: per frame read the 4 bar heights + total (pixel rows vs fixed ppm lines) -> 4 stacked voices (land low pad, ocean mid, biomass noise burst, fossil bright saw), pitch/volume = signed ppm; date = n x 3 h from frame index.

## Frame → time mapping

For the 2920-frame movies (equirect, regional globes, legend, timeline; waterfall has 2919): date = 2021-01-01T00:00 + (n-1) x 3 h for 1-based EXR numbering .00001..02920 (or n x 3 h for a 0-based video frame); day-of-year = floor(n/8)+1; t seconds = n/30, day = t x 3.75. Start/end alignment (00:00 vs 03:00 UTC for frame 1) is UNVERIFIED. Explainer frame at t=0 is black and last frame (t=119 s) is only the bar chart, so use the timeline-bar fraction there, not a formula.

## Gotchas

- Explainer mp4 frame at t=0 is black and its pacing is 3600 frames, so 'one frame = 3 h' only holds for the 2920-frame movies.
- Frame counts differ: equirect and waterfall movies ~2919, others 2920; NewTaggedCO2 equirect EXR numbering has one step of 2.
- No year on screen; 2021 comes only from the description text.
- Explainer 4K mp4 is 680.9 MB; EXR frame sets 7 to 33 GB: not browser usable.
- Globe camera moves, so the same pixel is a different place at different times.
- Last-Modified dates in 2024-2025 are re-encodes, not new data.
- 3-hourly cadence is INFERRED from frame count, not stated by NASA; GMAO FTP linked on the page (gmao.gsfc.nasa.gov/gmaoftp/lott/svs/tagged_co2/) may hold the true time axis.

Advanced computer modeling techniques in NASA's Global Modeling and Assimilation Office allow us to disentangle the influences of sources and sinks and to better understand where carbon is coming from and going to. ||
