## Gotchas

- STALE: newest data date is 2026-06-13, 154 days before 2026-11-14, even though the mp4s, frame listing and dates_list.txt were all rewritten on 14 Nov 2026 (Last-Modified 10:27-11:01 GMT).
- Do not trust Last-Modified or the page 'updated' stamp for data freshness; read dates_list.txt last line or the last frame label.
- 'Near real-time' and the abstract 'to the present' are not true today.
- The 11:01:43 GMT mp4 stamp matches the same minute as 5072's movies, suggesting a bulk touch.
- Frame-set listing is name-only: no sizes or mtimes; 8640x4320 PNGs are huge (not suitable for a 28 h browser build).
- Undated movie has 930 frames (31 s) vs 900 for the dated ones; frame i is not guaranteed to match day i beyond 899.
- Date format 'Dec 27, 2023' in dates_list.txt vs 'YYYYMMDD' in file names vs '27  Dec  2023' burned in (two spaces).
- Ocean is painted solid blue and snow white, so NDVI values are masked there; colour is a ramp, not raw NDVI numbers.
- Only two projections: equirectangular (use this) and Robinson (avoid).
- Time zone/UTC definition of each daily composite not stated.
- Added by the second agent: Undated movie (931 frames) has a ~1 s end hold; frames at t=0,0.5,1.0,1.5 all differ, so no start hold and frame i matches day i for i<900.
